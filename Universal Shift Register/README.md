# Universal Shift Register

## Project Overview

* Designed a 4-bit Universal Shift Register using Verilog HDL.
* Supports hold, right shift, left shift, and parallel load operations.
* Created a testbench to verify the design.
* Simulated and analyzed the output waveforms.

## Files

* `USR.v` — RTL design
* `tb_USR.v` — Testbench

## Tools

* Verilog HDL
* EDA Playground
* Icarus Verilog
