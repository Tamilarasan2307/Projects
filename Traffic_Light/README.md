# Traffic Light Controller

## Project Overview

* Designed a traffic light controller using Verilog HDL.
* Created the RTL design in EDA Playground.
* Created a testbench to simulate the design.
* Observed the controller's output behavior during simulation.

## Project Files

* `traffic_light.v` — RTL design of the traffic light controller.
* `tb_traffic_light.v` — Testbench for testing the design.

## Tools Used

* Verilog HDL
* EDA Playground
* EPWave

## Objectives

* Understand traffic light controller logic.
* Practice Verilog RTL design.
* Verify the design through simulation.

## Verification

* Applied input signals using the testbench.
* Observed output changes during simulation.
* Checked the controller's behavior against the intended operation.
